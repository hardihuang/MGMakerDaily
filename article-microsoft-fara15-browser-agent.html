微软Fara1.5：AI学会自己上网操作浏览器，72%任务成功率刷新纪录

传统的AI助手只能回答问题、生成文本，但无法真正"动手"操作电脑。微软最新发布的Fara1.5系列模型，让AI能像人类一样看屏幕、点鼠标、敲键盘，在浏览器中自主完成填表、比价、订票等复杂任务，27B版本在300项真实网页任务中达到72%的成功率，超越了OpenAI和谷歌的同级竞品。

【🔍 前沿聚焦】

我们日常使用电脑时，打开浏览器搜索信息、填写表单、比较商品价格，这些操作对人来说轻车熟路，但对AI而言却是巨大挑战——因为它需要同时理解网页布局、识别按钮位置、判断下一步该点击哪里。过去，AI只能处理文字对话，一旦涉及图形界面操作，就只能让人自己动手。

微软研究院AI Frontiers实验室最新发布的Fara1.5系列模型，采用了"观察—思考—行动"（Observe-Think-Act）循环机制：每一步都读取最近3张浏览器截图，结合对话历史输出推理过程和下一步操作。该系列提供4B、9B、27B三个参数规模，其中Fara1.5-27B在覆盖136个热门网站、300项任务的Online-Mind2Web基准测试中取得72%任务成功率，大幅超越OpenAI Operator（58.3%）和谷歌Gemini 2.5 Computer Use（57.3%）。训练数据包含约200万条样本，涵盖真实网页操作轨迹、合成环境模拟、表单填写和视觉问答等多种任务类型。

这项突破意味着AI从"只会说话"迈向"能干活"的关键跨越。Fara1.5搭配沙盒浏览器MagenticLite使用，在遇到缺少个人信息、任务描述模糊或即将执行不可逆操作时，会主动暂停并询问用户确认，所有操作记录可追溯，为智能助手真正走入日常办公场景铺平了道路。

🔑 核心科技关键词

Computer Use Agent (计算机使用智能体)：一种能够像人类一样操作图形界面（浏览器、桌面应用）的AI智能体。它通过截取屏幕图像识别界面元素，再输出鼠标点击、键盘输入等操作指令来完成任务，区别于只能通过API或文本交互的传统AI助手。

Observe-Think-Act Loop (观察-思考-行动循环)：Fara1.5的核心决策框架。每一步先"观察"最近3张浏览器截图，再"思考"当前状态和下一步策略，最后"行动"执行鼠标或键盘操作，三个环节循环推进直至任务完成。
